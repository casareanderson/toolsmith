# examples

Real output from the author's two weekly runs, sanitised: host names are generic, addresses
are RFC 5737 `192.0.2.x`, and notes file names are shortened. Numbers are unchanged.

- `facts-excerpt-reverse-proxy.txt`: part of a fact pack from `toolsmith-gather.py`
- `reports/`: what the owner received after validation
- `quarantine/`: what the validator withheld, and why (the reverse-proxy file is cut down)
- `validate-*.json`: the validator's stdout for each run
- `sandbox/`: every sandbox JSON so far: three self-tests and the two OpenLIT-week runs
